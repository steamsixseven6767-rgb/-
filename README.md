# RAM Stress Test (Fabric 1.20.1)

Раз в 5 минут выделяет ~95% доступной памяти кучи JVM и удерживает её 30 секунд,
затем освобождает. Игрок видит сообщения в чате: начало нагрузки, объём выделенной
памяти, освобождение.

## Важные предупреждения

- **Это реально может уронить игру.** Выделение 95% доступной памяти с высокой
  вероятностью вызовет `OutOfMemoryError` и краш клиента Minecraft — это ожидаемо
  для стресс-теста, а не баг.
- **Сохрани прогресс перед запуском.** Если играешь в мире с автосохранением —
  всё равно лучше выйти из важных несохранённых действий заранее.
- Мод трогает страницы памяти (`chunk[i] = 1` через каждые 4 КБ), чтобы ОС
  реально закоммитила выделенные страницы, а не просто зарезервировала виртуальный
  адрес — иначе тест не покажет честную нагрузку.
- Тест влияет **только на память процесса Minecraft/JVM**, не на всю ОС напрямую —
  но если у тебя мало общей RAM и активен своп, это всё равно может ощутимо
  просадить систему целиком.

## Сборка
```
./gradlew build
```
Jar появится в `build/libs/ram-stress-test-1.0.0.jar`.

## Установка
1. Fabric Loader для 1.20.1
2. Fabric API
3. Положить jar в папку `mods`

## Настройка
В `RamStressTestMod.java`:
- `INTERVAL_MS` — периодичность (по умолчанию 5 минут)
- `HOLD_MS` — как долго держать память (по умолчанию 30 секунд)
- `TARGET_FRACTION` — доля доступной памяти (по умолчанию 0.95)

Совет: если хочешь протестировать мягче, начни с `TARGET_FRACTION = 0.5–0.7`,
прежде чем пробовать 0.95 — так проще понять, на каком уровне у твоего устройства
начинаются проблемы (лаги ОС, своп, краш JVM), не сразу ловя краш вслепую.
